# 클라우드 세션 작업 목록 (2026-10-14)

클라우드 세션에서 "`docs/CLOUD_TASKS.md` 의 T1 해줘" 처럼 번호로 시킨다. 위에서부터 순서대로.

## 공통 규칙 (모든 작업)

- 답·보고·커밋 설명은 **한국어**. 물어보지 말고 끝까지 하고, 끝나면 한 번에 보고한다.
- 작업마다 `feat/…` 또는 `fix/…` 브랜치를 만들고, 테스트가 통과하면 main 에 머지해서 푸시한다.
- "됐다"는 말은 테스트·빌드를 직접 돌려 통과를 확인한 뒤에만 한다. 못 돌린 것은 못 돌렸다고 적는다.
- 클라우드에는 API 키(`.env`)가 없다. 키가 필요한 확인은 "PC에서 할 일"로 보고에 남긴다.
- 끝낸 작업은 이 파일에서 `⬜` 를 `✅ (날짜, 커밋)` 으로 바꾼다.
- 이 레포만의 규칙: 설치·검증 절차는 `AGENTS.md`. 이 레포는 **공개**라 비밀값·개인 정보는 절대 커밋하지 않는다. 남은 일 목록의 원본은 `docs/LAUNCH.md`.
