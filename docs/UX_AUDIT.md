# 사용자 편의 점검 (2026-10-26)

**방법:** 실제 서버 코드를 메모리 DB(PGlite)에 붙여 로컬에서 띄웠습니다. 헤드리스 크롬(아이폰 UA, 390×844)으로 두 사람(미나·레오)을 처음부터 끝까지 써 봤습니다.
첫 진입 → 상대 부르기 → 일정 넣기·고치기·지우기 → 처음 만난 날 → 알림 → 사진 → 설정 → 탈퇴 순서입니다.
구글 로그인만 직접 서명한 가짜 토큰을 썼습니다.

기준은 "토스라면 이걸 이렇게 두지 않았다"입니다. 표는 **효과 큼·작업 작음** 순입니다.
스크린샷은 `docs/handoff-shots/ux/`에 있습니다(`before-*`는 고치기 전, `after-*`는 고친 뒤).

## 실기기에서 확인이 필요한 것

- **아이폰 사파리 탭의 알림 버튼(4번)**: 누르면 3단계 안내가 뜨는지, 설명이 "지원 안 함"이 아니라 "홈 화면에 추가하면…"으로 나오는지
- **되돌리기 토스트(6번)**: 아이폰에서 토스트의 "되돌리기"가 잘 눌리는지(모달 위 popover). 그리고 지운 직후 홈 화면 앱을 바로 내려도 5초 안에 서버로 지우기가 가는지(숨겨질 때 keepalive로 보냄)
- **첫 화면 초대 카드(2번)**: 아이폰·안드로이드에서 공유 시트가 바로 열리고 카톡으로 보낼 수 있는지
- **연도 목록(3번)**: 연도 목록이 올해 근처로 스크롤되어 열리는지
