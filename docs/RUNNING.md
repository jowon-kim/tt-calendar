# 오래 굴리기

깔고 나서 알아야 할 것들입니다. 급하지 않지만 언젠가 걸리는 것들이에요.

## 돈이 나가는 자리

**둘이 쓰려고 직접 깐 한 벌**이면 전부 무료 구간 안입니다. **여러 커플에게 서비스로
내주면** 아래 ★ 둘은 유료가 필수예요.

| 무엇 | 무료 조건 | 서비스로 내주면 |
|---|---|---|
| **Vercel** | Hobby: 함수 호출·전송량 월 한도 | ★ **Pro 필수** — Hobby는 비상업·개인 용도만 허용. 돈을 안 받아도 남에게 내주면 해당 |
| **Neon** | Free: 컴퓨트 100 CU-hour · 저장공간 0.5GB | ★ **유료** — 커플마다 시간대가 달라 바깥 시계가 하루 종일 돌고, DB가 잠들 틈이 없습니다 |
| **Vercel Blob** (사진) | 무료 구간 있음 | 커플 수 × 사진. 한 장 10KB 안팎 |
| **구글 로그인** | 무료 | 구글 클라우드 콘솔의 OAuth 동의 화면을 "프로덕션"으로 올려야 아무나 씀 |
| **웹푸시 · FCM · APNs** | 무료 · 건수 제한 없음 | APNs는 애플 개발자 계정(연 $99) 안에 포함 |
| **GitHub Actions** | 공개 저장소면 macOS 러너 무료 | 비공개로 돌리면 macOS 분당 과금 |

**사진은 이제 DB 밖(Vercel Blob)에 둡니다.** 예전처럼 base64로 DB에 넣으면 커플이
늘수록 DB가 사진 창고가 됩니다. `BLOB_READ_WRITE_TOKEN`이 없는 설치만 예전 방식이에요.

**컴퓨트 시간이 유일하게 신경 쓸 값입니다.** Neon은 요청이 오면 깨어나고 5분 놀면
잠듭니다. 깨어 있는 시간만 소모돼요. 0.25 CU면 월 400시간까지 쓸 수 있는데, 둘이
하루 몇 번 열어보는 정도면 월 10시간도 안 됩니다.

- **동기화를 2분보다 자주 하지 마세요.** 더 자주 부르면 DB가 잠들지 못합니다
- 화면을 보고 있을 때만, 10분 이상 안 만지면 쉬도록 이미 짜여 있습니다
- Neon 신규 프로젝트는 기본 최소 컴퓨트가 0.25 CU입니다. **올리지 마세요**

## 손대면 안 되는 것

**`app_meta` 표.** 앱이 처음 켜질 때 스스로 만든 열쇠들이 들어 있습니다
(`lib/setup.js`). 줄을 지우거나 고치면 새로 만들어지는데, 그러면

- `vapid` — 브라우저가 만든 구독에 박혀 있던 키라 **켜둔 브라우저의 알림이 전부 죽고**
  모두 설정에서 다시 켜야 합니다 (스토어 앱 알림은 상관없음)
- `cron_secret` — `CRON_SECRET`을 안 넣은 설치에서만 쓰입니다. 바뀌면 바깥 시계가 401을 받아요
- `diary_secret` — 한 쌍용 판의 로그인 열쇠입니다. 이제 안 씁니다 (남아 있어도 무해)

## 백업

Neon 무료 플랜은 6시간 복원 창만 줍니다. 그래서 `.github/workflows/backup.yml`이 **매일 새벽 3시(한국)**
DB를 통째로 떠서 **암호화한 뒤** Actions 아티팩트로 30일 보관합니다. 저장소가 공개라 아티팩트는
누구나 받을 수 있어서, 암호를 모르면 못 열게 잠급니다.

켜려면 저장소 Settings → Secrets and variables → Actions에 둘을 넣으세요. 없으면 아무것도 안 하고 끝납니다.

| 시크릿 | 값 |
|---|---|
| `BACKUP_DATABASE_URL` | Vercel 환경변수 `DATABASE_URL_UNPOOLED` 값 (pooler를 거치지 않는 연결) |
| `BACKUP_PASSPHRASE` | 길고 무작위한 암호. **잃어버리면 백업을 못 엽니다** — 비밀번호 관리자에 따로 |

넣은 뒤 Actions → backup → Run workflow로 한 번 돌려 파일이 생기는지 보세요.

되살리기:

```bash
gpg --decrypt diary-XXXX.dump.gpg > diary.dump      # 암호를 묻습니다
pg_restore --no-owner --no-privileges -d "<새 DB 연결 문자열>" diary.dump
```

**사진 파일(Vercel Blob)은 백업에 안 들어갑니다.** 사진이 어디 있는지 적힌 줄만 들어가요.
서비스로 굴린다면 Neon 유료 플랜의 복원 기간도 같이 확인하세요.

## 시간이 지나면 손봐야 하는 것

**아이폰 웹푸시가 조용히 끊깁니다.** iOS 쪽 알려진 성질입니다. 앱을 열 때 구독이
사라졌으면 도로 걸어둡니다 — 권한은 남아 있어서 다시 물어보지 않고 조용히 됩니다.
그래도 안 오면 설정에서 껐다 켜세요. 앱을 지웠다 다시 깔면 권한부터 없어집니다.

**공휴일 표가 2036년까지입니다.** 음력에 매인 설날·추석·부처님 오신 날은 계산으로
못 구해서 `public/app.js`의 `LUNAR_DAYS`에 적어두었습니다. 표에 없는 해는 양력
공휴일만 뜨니, 그때 한국천문연구원 발표 날짜를 몇 해 더 붙이면 됩니다.
대체공휴일은 규칙(관공서의 공휴일에 관한 규정 제3조)대로 알아서 붙습니다.

**Node 버전은 `package.json`의 `engines`(20 이상)로 박아뒀습니다.**

**바깥에서 끌어오는 것 둘** — 글꼴입니다.

| 어디서 | 무엇 | 없으면 |
|---|---|---|
| `fonts.googleapis.com` | Gowun Batang (제목) | 기본 명조로 떨어짐 |
| `cdn.jsdelivr.net` | Pretendard (본문) | `-apple-system`으로 떨어짐 |

둘 다 버전을 박아뒀으니 어느 날 모양이 바뀔 일은 없고, CDN이 죽어도 **글꼴만
기본체로 떨어지고 달력은 그대로 돕니다.** 손글씨체는 `public/fonts/`에 넣어뒀습니다.

**배포에 실리는 라이브러리는 셋뿐입니다.** FCM·APNs는 SDK 없이 fetch와 Node 내장 http2로 보냅니다.

| | 쓰는 곳 |
|---|---|
| `@neondatabase/serverless` | DB 연결 |
| `web-push` | 브라우저 알림 |
| `@vercel/blob` | 달력 사진 |
| `@electric-sql/pglite` | 테스트에서만 (`--omit=dev`로 배포엔 안 올라감) |
| `@capacitor/*` | 스토어 앱 빌드할 때만 (배포엔 안 올라감). 올리면 `npm run vendor`로 `public/vendor/capacitor.js`도 갈아야 합니다 — 안 맞으면 화면 테스트가 잡습니다 |

`npm outdated`로 확인하고, 올린 뒤엔 `npm test`가 통과하는지만 보면 됩니다.

**무료 조건은 회사가 바꿀 수 있습니다.** 위 표는 이 문서를 쓴 시점 기준이라,
1년쯤 뒤에는 Vercel·Neon 요금 페이지를 한 번 확인해 보세요.

## 여러 커플이 한 배포를 쓰는 구조

이제 계정(아이디·비밀번호 또는 구글)으로 들어오고, 달력은 커플마다 따로입니다(`couple_id`).
예전 "한 쌍이 한 벌씩 설치"하던 판에서 막혀 있던 두 가지가 풀렸어요.

- `settings`의 `check (id = 1)` 제약을 없애고, 달력을 만지는 모든 쿼리가 `couple_id`로 거릅니다
  (`lib/store.js`). `test.mjs`의 두 커플 구간이 모든 창구를 두드려 새는지 봅니다
- 사진 주소도 이제 로그인한 그 달력 사람만 엽니다 (로그인 쿠키가 `<img>` 요청에도 실려서)

**아직 안 한 것** — 결제, Postgres RLS(DB가 한 번 더 막는 장치. 지금은 앱에서만 거릅니다), 구글·애플 캘린더 연동.
