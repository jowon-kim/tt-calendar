## 로컬에서 띄워 보기

```bash
npm install
npm test          # 서버 386 · 화면 219 · i18n · 공휴일 · 서비스워커 · 공개 페이지 (전부 통과 상태)
npm run i18n      # 9개 언어 100%
npm run local     # tools/dev-local.mjs — 진짜 api/ + 메모리 Postgres, 가짜 구글 로그인. http://127.0.0.1:8787
```

`npm run local`은 Neon·Vercel·구글 계정 없이 돕니다. 들어가는 법은 `tools/dev-local.mjs` 맨 위 주석에 있습니다.
UX 점검 때 헤드리스 크롬(아이폰 390×844)으로 처음부터 끝까지 쓴 것도 이 서버였습니다.

### 실기기 확인 (클라우드에서 못 함)
- **아이폰 사파리**
  - 첫 진입: 이름 → 3단계 그림 안내 → 사용법
  - 설치 안내 문구("더 보기", "웹 앱으로 열기")가 실제 iOS 26 표기와 맞는지. 한국어·영어 말고 7개 언어는 확인 안 됨
  - 설정의 "알림 받기"를 누르면 그림 안내가 뜨는지
- **되돌리기 토스트**: 토스트가 잘 눌리는지. 지운 직후 앱을 내려도 5초 안에 서버에서 지워지는지
- **"레오님이 들어왔어요" 알림**: 폰 두 대로 확인. 웹·안드로이드·아이폰 모두
- **첫 화면 카드**: 초대 카드는 공유 시트가 열리는지, 처음 만난 날 카드는 연도 목록이 바로 뜨는지
- **사진**: 사진이 없을 때 "사진 설정"을 누르면 사진 보관함이 바로 열리는지
- **밤 테마**: 토스트와 체크 상자가 잘 보이는지
- **안드로이드 크롬**: 이름 → 설치 제안 → 시스템 설치 창이 뜨는지
