# OKKY 초안 — 홍보·광고 게시판

규칙 요약: 자기 서비스 소개는 **홍보·광고 게시판에만.** 다른 게시판에 올리면 무통보 이동·비공개됩니다.
OKKY는 개발자가 많아서, 무엇을 어떻게 만들었는지를 중심으로 씁니다.

**제목:** [무료 베타] 프레임워크·빌드 없이 만든 커플 공유 달력 TT — 상대가 일정을 바꾸면 알림

**본문:**

> 직접 만든 서비스라 홍보 게시판에 올립니다.
>
> **무엇인가요**
> 둘이 같이 쓰는 달력입니다. 한쪽이 일정을 넣거나 고치거나 지우면 상대 폰에 알림이 갑니다(내가 바꾼 건 나한테 안 옵니다).
> 시간이 있는 일정은 30분~1시간 전에, 아침 8시엔 오늘 일정을 모아서 한 번 더 알려 줍니다.
> 사귄 날을 넣으면 100일 단위·기념일이 달력에 표시됩니다. 지금은 무료 베타이고 광고는 없습니다.
>
> 주소: https://tt-calendar.vercel.app/ko/
> (브라우저에서 바로 열리고, 홈 화면에 추가하면 앱처럼 씁니다. 아이폰은 홈 화면에 추가해야 알림이 옵니다 — iOS 16.4 이상)
>
> **만든 방식** (궁금해하실 것 같아서)
> - 프레임워크·번들러 없이 순수 JS. HTML 하나, 스크립트 하나, CSS 하나를 Vercel이 그대로 내줍니다.
>   안드로이드·iOS 앱은 같은 파일을 불러오는 Capacitor 껍데기입니다
> - 런타임 의존성 3개(Neon 서버리스 드라이버, web-push, Vercel Blob). FCM·APNs는 SDK 없이 JWT 서명 + fetch / Node http2,
>   구글 로그인은 ID 토큰을 구글 공개키로 `crypto`가 직접 검증합니다
> - 여러 커플이 한 배포를 같이 쓰는 구조라, 모든 쿼리가 커플 ID를 먼저 받고 "두 커플 테스트"가 모든 API를 두드려 남의 달력이 보이는지 확인합니다
> - 테스트는 PGlite(메모리 Postgres)로 실제 SQL을 돌려서 계정 없이 `npm test` 하나로 약 590개
> - 무료 한도에 맞추려고 바깥 cron이 30분마다 두드리고 그 사이엔 DB가 잠듭니다. 매일 밤 GitHub Actions가 DB를 암호화해서 백업합니다
>
> **아직 부족한 점**
> - 달력 하나에 시간대가 하나라, 서로 다른 나라에 있는 커플은 시간이 한쪽 기준으로 보입니다
> - 로그인은 구글 하나뿐입니다
>
> 써 보시고 막히는 곳(특히 구글 로그인 → 초대 링크 → 홈 화면 추가 흐름)을 알려 주시면 고치겠습니다.
